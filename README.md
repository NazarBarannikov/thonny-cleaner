# thonny-cleaner
Удалить украинскую политическую пропаганду из интерфейса среды Thonny 5.0.0 на Linux.
В терминале Linux выполнить команду, указав реальный путь к папке thonny-cleaner:

    sudo bash /путь/к/папке/thonny-cleaner/thonny-cleaner.sh

Внимание! Работоспособность скрипта на версиях Thonny, отличающихся от 5.0.0 не гарантируется!
После обновления или переустановки программы скрипт может потребовать повторного выполнения!
